L'image et le logo

Le repère n'apparaît pas dans le fichier téléchargé. Facebook rogne les bords selon l'appareil : gardez l'essentiel à l'intérieur. Sur la bannière de page, le bleu est ce que le téléphone rogne, le rouge l'avatar sur ordinateur, l'orange l'avatar sur téléphone ; le logo n'y est pas dessiné, l'avatar le montre déjà.
Les illustrations viennent d'Open Doodles et d'Open Peeps, sous licence CC0, recolorées aux couleurs du logo. Les polices sont Source Serif 4 et Source Sans 3, sous licence libre. Rien n'est envoyé sur Internet : tout se passe dans ce fichier.
